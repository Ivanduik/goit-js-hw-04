# goit-js-hw-04

Домашнє завдання №4 із JavaScript: робота з об'єктами.

- `js/task-1.js` — підрахунок кількості товарів і перевірка місткості.
- `js/task-2.js` — середня кількість калорій за дні.
- `js/task-3.js` — методи профілю користувача та `this`.

Відкрийте `index.html` у браузері та перевірте DevTools → Console.
